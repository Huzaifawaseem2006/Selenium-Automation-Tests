# Selenium Automation Tests

A collection of Selenium WebDriver automation projects built in C# using MSTest, 
covering UI automation, Page Object Model, data-driven testing, and test reporting.

## Projects

| Project | Description |
|---|---|
| **Selenium Basics** | Selenium fundamentals — login tests, dropdowns, element validation, positive/negative test cases |
| **Demo QA** | 12 automated test cases on demoqa.com — checkboxes, radio buttons, web tables, click actions, links |
| **Page Object Model** | POM implementation with BasePage, LoginPage, SearchPage and ExtentReports HTML reporting |
| **Data Driven** | Data-driven testing using external XML data sources |
| **Selenium Allure** | Allure reporting integration with severity levels, tags, owners, and suite metadata |

## Tech Stack
- Selenium WebDriver (C#)
- MSTest
- ExtentReports
- Allure Reports
- ChromeDriver
